Build a complete, production-ready Telegram bot in Python for construction site inspection reports (EnigmaTech Inspection Bot).

### 1. Environment Variables (Secrets)
Use environment variables for:
- `TELEGRAM_BOT_TOKEN`
- `GEMINI_API_KEY`

Ensure the bot starts cleanly using `python-telegram-bot` (v20+) with `drop_pending_updates=True` to avoid polling conflicts.

### 2. Core Functionality & Commands
Maintain an in-memory session per `chat_id` storing lists of `photos` (file path + optional caption), `voices` (file path), and `notes` (text strings).

- `/start` or `/help`: Reply in Hebrew explaining what the user can send (photos with or without captions, voice messages, text notes) and list available commands (`/report` to generate the Word report, `/clear` to reset the session).
- `/clear`: Clear all saved photos, voice recordings, and text notes for that user and reply in Hebrew: "🗑️ כל התמונות, ההקלטות והערות הטקסט שנשמרו נוקו."
- **Photo Handler**: Download the highest-resolution photo to a temp directory, save its local path and caption (if any), and reply in Hebrew: `📸 תמונה #{index} נשמרה.`
- **Voice/Audio Handler**: Download voice notes or audio files (`.ogg`/`.mp3`) to a temp directory, save the path, and reply in Hebrew: `🎙️ הקלטה #{index} נשמרה.`
- **Text Handler** (non-command messages): Save the text note to the session and reply in Hebrew: `✅ הערת הטקסט נשמרה.`
- `/report`:
  1. If the session is empty, reply in Hebrew: "⚠️ לא נשמרו עדיין תמונות, הקלטות או הערות טקסט. שלח חומרים לבוט ולאחר מכן הפעל שוב /report."
  2. Otherwise, reply in Hebrew: "⏳ מעבד את ההקלטות והתמונות ובונה את הדוח... אנא המתן."
  3. Send all saved text notes, voice recordings (as audio parts), and photos (with their index and captions) to the Google Gemini API using the official `google-genai` SDK (`from google import genai`).
  4. **Important Gemini Model Rule**: Use `gemini-3.8-flash` (or dynamically fall back to the latest available Flash model if needed, do NOT use deprecated `gemini-2.5-flash`).
  5. Prompt Gemini in Hebrew to act as a construction quality control & site inspection engineer and generate a structured, professional inspection report in clean Hebrew under three headings:
     - `## תקציר מנהלים`
     - `## ממצאים וליקויים בשטח`
     - `## פעולות נדרשות והמלצות לביצוע`
     Instruct Gemini to reference each photo by its number (`תמונה #1`, `תמונה #2`, etc.) and transcribe/integrate all voice recordings and text notes without extra markdown asterisks.

### 3. Word Document (.docx) Generation & RTL Formatting
- Use `python-docx` to build a clean Word document.
- Every paragraph and heading MUST be properly formatted as Right-to-Left (RTL) for Hebrew: set `paragraph.alignment = WD_ALIGN_PARAGRAPH.RIGHT`, add `<w:bidi/>` to paragraph properties (`pPr`), and add `<w:rtl/>` to run properties (`rPr`) using Arial font.
- Add a main title with the current date and time: `דוח פיקוח וסיור בשטח - DD/MM/YYYY HH:MM`.
- Parse the Gemini response cleanly into headings and body paragraphs.
- Append a section at the end titled `נספח תמונות מהשטח` containing each photo labeled (`תמונה #1: [caption]`) and embedded centered (width ~5 inches).
- **Encoding Rule**: Save the file using an ASCII-only filename (e.g., `EnigmaTech_Report_YYYYMMDD_HHMMSS.docx`) to avoid any HTTP/Telegram ASCII encoding errors, and send it back to the user via `reply_document` with a Hebrew caption: `📄 הדוח מוכן! מצורף קובץ Word מסודר.`
- Clear the user's session and clean up temporary files after sending the report.

### 4. Error Handling & Reliability
- Wrap `/report` in a `try/except` block that sends a clear error message to the user if anything fails.
- Make sure the bot runs continuously and recovers gracefully from network hiccups.
